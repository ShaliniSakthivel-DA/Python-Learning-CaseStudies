# NumPy Fundamentals and Student Marks Analysis Using Python

## Overview
This project introduces the fundamentals of NumPy, one of the most powerful libraries for numerical computing in Python. The notebook covers array creation, array operations, shape analysis, and a real-world Student Marks Analysis case study using NumPy arrays.

## Topics Covered

### NumPy Basics
- Installing NumPy
- Importing NumPy
- Creating NumPy arrays

### Array Creation
- One-Dimensional (1D) Arrays
- Two-Dimensional (2D) Arrays
- Array data types

### NumPy Functions
- `np.array()`
- `np.arange()`
- `np.linspace()`
- `np.shape()`

### Array Operations
- Accessing array elements
- Array dimensions
- Mathematical operations
- Statistical calculations

## Case Study: Student Marks Analysis

### Objective
Analyze student performance using NumPy arrays and statistical functions.

### Operations Performed
- Store student marks in a NumPy array
- Calculate total marks for each student
- Calculate average marks
- Find highest and lowest marks
- Calculate percentage scores
- Identify students scoring above average
- Identify failed students
- Calculate subject-wise averages
- Generate student performance reports
- Rank students based on total marks

### Key Outputs
- Student Marks Matrix
- Total Marks
- Average Marks
- Highest and Lowest Marks
- Percentage Calculation
- Overall Average
- Above Average Students
- Failed Students
- Subject-wise Average
- Student Report Card
- Student Ranking

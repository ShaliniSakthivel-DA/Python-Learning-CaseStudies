# Python While Loop Practice Programs and Case Studies

## Overview
This project contains multiple Python programs created for practicing `while` loops and conditional statements.  
The notebook is designed for beginners who are learning Python fundamentals with simple real-time examples and mini case studies.

---

## Topics Covered

### 1. Basic While Loop
- Print numbers from 1 to 20
- Loop termination example

### 2. Even Numbers Program
- Print even numbers from 1 to 100

### 3. Odd Numbers Program
- Print odd numbers from 1 to 100

### 4. List Iteration Using While Loop
- Access student names using indexing
- Understanding `IndexError`

### 5. Password Verification System
- Validate password using `while` loop
- Display access messages

### 6. ATM PIN Verification System
- Real-time ATM login simulation
- Uses infinite loop with `break`

### 7. Maximum Login Attempts
- Limit login attempts to 3
- Display remaining attempts

### 8. Continue Statement Example
- Skip even numbers
- Print only odd numbers

### 9. Student Marks Filter
- Display students scoring below 50
- Uses `continue` statement

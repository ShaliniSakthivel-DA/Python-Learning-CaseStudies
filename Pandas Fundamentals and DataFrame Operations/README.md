# Pandas Fundamentals and DataFrame Operations in Python

## Overview
This project introduces the fundamentals of Pandas, one of the most widely used Python libraries for data analysis and manipulation. The notebook covers Series, DataFrames, data selection, filtering, sorting, indexing, and updating data through practical examples.

## Topics Covered

### 1. Installing and Importing Pandas
- Installing Pandas using pip
- Importing Pandas as pd

### 2. Pandas Series
- Creating a Series
- Understanding 1D labeled arrays
- Viewing Series data and data types

### 3. Creating DataFrames
- Creating DataFrames from dictionaries
- Creating DataFrames from lists
- Working with rows and columns

### 4. Accessing Data
- Selecting single columns
- Selecting multiple columns
- Accessing rows using slicing

### 5. DataFrame Indexing
#### loc[] - Label-Based Indexing
- Accessing specific rows and columns
- Selecting multiple rows and columns

#### iloc[] - Integer-Based Indexing
- Accessing data using row and column positions
- Comparing loc[] and iloc[]

### 6. Filtering Data
- Applying conditions
- Filtering using multiple conditions
- Extracting specific records

### 7. Sorting Data
- Sorting DataFrames using column values
- Sorting records in ascending order

### 8. Adding New Records
- Adding rows using loc[]
- Dynamically inserting records

### 9. Updating Data
- Modifying column values
- Updating records using conditions
- Editing existing DataFrame entries

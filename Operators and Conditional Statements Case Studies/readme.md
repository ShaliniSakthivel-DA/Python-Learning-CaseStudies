# Python Operators and Conditional Statements Case Studies

## Project Overview
This project contains basic Python programs to practice:
- Python Operators
- Conditional Statements
- Nested If Conditions
- User Input Handling

The notebook is designed for beginners to understand Python concepts with simple examples and case studies.

## Topics Covered

### Python Operators
- Arithmetic Operator
- Comparison Operator
- Logical Operator
- Membership Operator
- Identity Operator
- Assignment Operator

### Conditional Statements
- if Statement
- if else Statement
- elif Statement
- Nested if Statement

## Case Studies Included
1. Vote Eligibility Checker
2. Odd or Even Number Checker
3. Positive or Negative Number Checker
4. Vowel Checker
5. Student Grade Checker
6. Bank Loan Eligibility System
7. Scholarship Eligibility Checker

## Technologies Used
- Python
- Google Colab

## Features
- Beginner-friendly examples
- User input programs
- Real-time condition checking
- Simple and readable code

## Learning Outcome
After completing this project, learners can understand:
- How operators work in Python
- How conditional statements are used
- How to build simple logic-based applications

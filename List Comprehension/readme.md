# Python List Comprehension – Practice Case Studies

## Description
This repository contains beginner-friendly Python programs using List Comprehension concepts.

The notebook covers multiple examples and mini case studies to practice:
- List creation
- Conditional filtering
- Mathematical operations
- String analysis
- Salary analysis

These exercises help learners understand Python list comprehension in a simple and practical way.

---

## Topics Covered

### Basic List Comprehension
- Generate numbers using range()
- Multiplication using list comprehension

### Even & Odd Numbers
- Find even numbers from 1 to 100
- Find odd numbers from 1 to 100

### String Analysis
- Convert text to uppercase
- Extract vowels
- Extract consonants
- Remove spaces from strings

### Salary Analysis
- Increase salary by 10%
- Filter salaries greater than 50000

### Data Filtering
- Filter positive numbers
- Filter sales greater than 1000
- Calculate total sales amount

---

## Technologies Used
- Python 3
- Google Colab
- Jupyter Notebook

---

## Learning Outcome
By completing these exercises, learners can understand:
- Python List Comprehension syntax
- Conditional filtering
- Data transformation techniques
- String handling using lists
- Real-time data analysis basics

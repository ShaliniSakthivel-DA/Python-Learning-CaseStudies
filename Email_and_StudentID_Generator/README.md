# Python Email and Student ID Generator

## Description
This project demonstrates basic Python string operations by generating an Email ID and Student ID using user inputs. It includes concepts like string methods, concatenation, slicing, split, join, formatting, and input handling.

## Features

### 1. Email ID Generator
- Takes full name as input
- Converts text to lowercase
- Replaces spaces with underscores
- Generates an email ID with domain name

**Example Output:**
```text
shalini_sakthivel@gmail.com
```

### 2. Student ID Generator
- Takes student name, roll number, and department
- Converts text to uppercase
- Uses slicing to create a short student ID

**Example Output:**
```text
SHALICOMPU25
```

### 3. String Operations Used
- `lower()`
- `upper()`
- `replace()`
- `split()`
- `join()`
- String slicing
- String concatenation
- f-strings

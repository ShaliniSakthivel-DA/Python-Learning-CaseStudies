# Python User Defined Functions and Case Studies

## Overview
This repository contains Python examples demonstrating **User Defined Functions (UDFs)**, different types of function arguments, variable scope concepts, and practical case studies. The notebook is designed for beginners to understand how functions work in Python through simple examples and hands-on exercises.

## Topics Covered

### 1. User Defined Functions
- Function creation and calling
- Parameters and arguments
- Return statements
- Multiple return values

### 2. Types of Functions
- Function without arguments and without return value
- Function with arguments and without return value
- Function without arguments and with return value
- Function with arguments and with return value

### 3. Function Arguments
- Positional Arguments
- Keyword Arguments
- Default Arguments
- Variable-Length Arguments (`*args`)
- Keyword Variable-Length Arguments (`**kwargs`)

### 4. Variable Scope
- Local Variables
- Global Variables
- Modifying Global Variables using `global`

## Case Studies

### Arithmetic Calculator Using Functions
A calculator program that:
- Accepts two numbers from the user
- Performs addition, subtraction, and multiplication
- Returns multiple values
- Displays calculated results

### Student Marks Analysis Using Functions and Loops
A marks analysis program that:
- Uses a list of student marks
- Displays marks using a loop
- Calculates total marks
- Calculates average marks
- Returns and displays results

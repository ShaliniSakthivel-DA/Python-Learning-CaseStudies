# College Event Management System using Python Collections

## Project Overview
This project is a simple Python-based College Event Management System created to demonstrate the usage of Python collection data types such as:

- List
- Tuple
- Set
- Frozenset

The program performs different operations related to college events, participants, departments, and winners.

---

## Features

### 1. Participants Management
- Add participants
- Insert participants
- Remove participants
- Display participant list

### 2. Events Management
- Store events using tuples
- Display:
  - First event
  - Last event
  - Total number of events

### 3. Department Management
- Add duplicate department names
- Remove duplicates using sets
- Perform add and remove operations in sets

### 4. Winners Management
- Store winners using tuples
- Convert winners list into a frozenset

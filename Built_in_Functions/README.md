# Python Built-in Functions, Lambda Expressions, Map and Filter Operations

## Overview
This project demonstrates the use of Python's built-in functions along with Lambda Functions, `map()`, and `filter()` operations. It includes practical examples and a real-world case study to help beginners understand functional programming concepts in Python.

## Topics Covered

### 1. Lambda Functions
- Creating anonymous functions using `lambda`
- Addition using lambda
- Square of a number using lambda

### 2. Lambda Functions with map()
- Converting string values to integers
- Squaring numbers in a list
- Rounding decimal values

### 3. Lambda Functions with filter()
- Filtering even numbers
- Filtering odd numbers
- Applying conditions to datasets

### 4. Python Built-in Functions
- `max()`
- `min()`
- `sum()`
- `len()`
- `round()`

## Case Study: Employee Salary Analysis

### Objective
Analyze employee salary data using Python built-in functions, lambda expressions, `map()`, and `filter()`.

### Operations Performed
- Store employee salaries in a list
- Find maximum salary
- Find minimum salary
- Calculate total salary
- Count the number of employees
- Increase salaries by 10% using `map()`
- Filter salaries greater than 50,000 using `filter()`

### Sample Output
- Original Salary List
- Updated Salary List
- High Salary List
- Maximum Salary
- Minimum Salary
- Total Salary
- Employee Count

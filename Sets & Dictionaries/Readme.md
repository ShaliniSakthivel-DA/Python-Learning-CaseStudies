# 📚 Student Course Registration & Data Management System

## 📌 Overview
This project is a simple Python-based case study that demonstrates how to manage student course registrations using **Sets** and **Dictionaries**. It helps in understanding how data structures can be used to store, update, and manage real-world data.

---

## 🎯 Features

### 🔹 Course Management (Using Set)
- Stores unique course names (duplicates automatically removed)
- Add new courses using `add()`
- Add multiple courses using `update()`
- Remove courses using `remove()` and `discard()`
- Display total number of courses
- View all available courses

### 🔹 Student Management (Using Dictionary)
- Stores student details (name, age, course)
- Add new student data dynamically
- Display all student records
- Access individual student details

---

## 🧠 Concepts Used
- Python Sets
- Python Dictionaries
- List Operations
- Data Manipulation
- Indexing & Accessing Elements

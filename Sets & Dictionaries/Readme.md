# 🎓 Student Course Registration & Data Management System

## 📌 Project Overview
This Python case study demonstrates how to manage student course registration and student data using **Sets and Dictionaries**.

It helps in understanding how to store, update, and manipulate structured data efficiently using Python.

---

## 🛠 Technologies Used
- Python

---

## 📚 Concepts Covered
- Python Sets
- Python Dictionaries
- List Operations
- add(), update(), remove(), discard()
- Indexing & Data Access
- len() function

---

## 📋 Program Features

### 🔹 Course Management (Using Set)
- Stores unique course names automatically
- Adds new course using `add()`
- Adds multiple courses using `update()`
- Removes a course using `remove()`
- Safely removes using `discard()`
- Displays total number of courses
- Prints final course list

### 🔹 Student Data Management (Using Dictionary)
- Stores student details (name, age, course)
- Adds new student data dynamically
- Displays all student records
- Retrieves individual student details

# 📖 Overview

This notebook demonstrates various Python List methods and operations commonly used in Python programming and Data Analytics.

- Creating Lists
- Accessing List Items

- `count()`

- `key=len`
- `copy()`
- `clear()`
- List Slicing

---

# 📝 Code Examples

## Sort List

```python
Fruits = ['Mango', 'Apple', 'Banana', 'Cherry']

Fruits.sort()
print(Fruits)
```

---

## Sort List in Reverse Order

```python
Fruits.sort(reverse=True)
print(Fruits)
```

---

## Sort Using String Length

```python
Fruits.sort(key=len)
print(Fruits)
```

---

## Create Sorted Copy

```python
new_Fruits = sorted(Fruits)
print(new_Fruits)
```

---

## List Slicing

```python
print(Fruits[1:3])
```
